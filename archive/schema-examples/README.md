# Archived Schema Examples

These example files originally sat beside the schemas in `schemas/`. They pre-date the schema revision (participant `type` became an object, and offerings gained the required `capability_matching` block), so they no longer validate. Nothing referenced them.

Archived on 2026-10-10 during WP10 (see [code review finding S2](../../docs/design/analysis/code-review-2026-10.md)). Validated examples live in [`examples/`](../../examples/). The richer service descriptions here (capability mappings, skillset boundaries, physical and access details) are useful source material for WP12 capability translation tests.
